# liczip（リックジップ）

配布用ZIPの中身を検査して、**ライセンス的に混入するとまずいファイル**を洗い出すブラウザツールです。
単一HTMLファイルで動き、ZIPはブラウザの中だけで処理します。サーバーへの送信は一切しません。

**ブラウザでそのまま使う**：https://kawahara-dev.github.io/liczip/
（ダウンロードしてローカルで開いても使えます）

## こんなときに

- BOOTHなどでダウンロード商品を配る前に、同梱素材のライセンスを確認したい
- ライブラリや素材を集めて作った配布物に、コピーレフトや商用不可の素材が混ざっていないか見たい
- 帰属表示やライセンス文の同梱など「やること」を一覧で把握したい

## 使い方

1. `liczip.html` をブラウザで開く
2. 配布用ZIPを1件、選択またはドラッグ＆ドロップする
3. 配布形態（有料・商用／無料配布／OSSとして公開）を選んで「ZIPを検査」を押す
4. 結果を確認する：リスク別のサマリー、ファイル別の判定表（検出ライセンス・根拠・リスク・必要な対応）、義務チェックリスト
5. 必要なら結果をMarkdownレポートとしてコピー／ダウンロードする

配布形態を変えると、読み込み済みの検出結果のままリスクを再判定できます。

## 検出できるもの

- ライセンスファイル（LICENSE / COPYING / NOTICE 等）の本文分類：MIT、BSD、Apache-2.0、ISC、Unlicense、CC0、GPL、LGPL、AGPL、MPL、EPL、CC各種（BY / BY-SA / BY-NC / BY-NC-SA / BY-ND）
- ソースファイル先頭の `SPDX-License-Identifier:` 宣言
- ライセンスの適用範囲（ライセンスファイルが置かれたディレクトリ配下への紐づけ）
- ZIP内ZIPの1階層までの検査
- NOTICE / AUTHORS / CREDITS など帰属情報ファイルの有無

## 仕様・制限

- 対応する圧縮方式は stored / deflate。ZIP64、分割ZIP、暗号化ZIPは対象外です
- ファイル名・本文の文字コードは UTF-8 / CP932系に対応します
- 入力上限：ZIP本体 100MiB、展開後の実測 32MiB など、巨大なZIPから守る上限を設けています
- 依存マニフェスト（package.json 等）の解析、バイナリ解析、フォントの埋め込み可否判定は行いません

## 注意（大事）

本ツールはライセンス表記の**機械的な検出を支援するもの**です。
検出の完全性、法的判断、配布の可否、ライセンス条件への適合を保証しません。
判定は代表的な英語表記の文面パターンに基づきます。最終確認は、必ず各ライセンスの原文と配布条件をご自身で確認してください。

## 動作環境

- モダンブラウザ（Chrome / Edge / Firefox / Safari の現行版）。deflate 展開に `DecompressionStream` を使うため、未対応ブラウザでは stored 形式のみ検査できます
- オフライン動作可。外部通信はしません（CSP で `connect-src 'none'` を指定）

## テスト

サンプルZIPの生成と自動テスト（Node.js）：

```sh
python3 generate_samples.py   # samples/ にサンプルZIPを生成
node --test --test-isolation=none test_liczip.mjs
```
